VERSION=1.9.15

[NEW FEATURES]
Server version updates now pick the Minecraft version first, then show only the loader builds that belong to it. The loader card reuses the same selection, so you no longer choose the parent version twice.

Large downloads are split into parallel segments. Set "Threads" and "Simultaneous downloads" in Settings > Downloads & Mirrors to match your connection (up to 128 threads).

The server update page now has a download mirror toggle and a custom mirror field, so version files and mod updates can use your own accelerator.

Forge and NeoForge installations now download libraries through a Maven mirror, so first-time installs work even when maven.neoforged.net is unreachable.

[IMPROVEMENTS]
The About page lists MingsiAmz as a contributor for the Chinese localization, download mirrors and hybrid server support.

[FIXES & STABILITY]
Fixed mirror 404s for Mojang libraries and assets by mapping them to the mirror's /maven and /assets layouts.
If the installer mirror patch fails, the original Forge/NeoForge installer is used unchanged.
